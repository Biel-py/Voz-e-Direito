# Voz-e-Direito
Voz e Direito é uma plataforma de letramento jurídico que traduz o "juridiquês" para uma linguagem simples e acessível. O projeto explica o funcionamento da Justiça brasileira, dos Três Poderes e dos Ministérios por meio de conteúdos interativos, promovendo cidadania, educação e acesso à informação jurídica.
